スマートフォンで使う（オフライン対応）
========================================

このサイトはスマートフォンのホーム画面に追加できるPWAとして準備されています。
一度HTTPSのサイトとして開くと、画面・JavaScript・スタイル・ペルソナ個別ページを端末へ保存し、次回以降はオフラインでも利用できます。

データについて
--------------
- 記録はアプリを開いたブラウザ／端末の中だけに保存されます。サーバーへの同期や送信はしません。
- PCブラウザの保存データはスマートフォンへ自動では移りません。必要ならPCで「バックアップを書き出す」を行い、JSONをスマホへ送り、スマホで一度だけ「バックアップを読み込む」を行ってください。
- 以後、スマホでの記録はスマホ内で続きます。PCとは同期しません。

公開・設置の準備
----------------
Service Workerによるオフライン保存にはHTTPSが必要です。file:// で直接開いたページや、通常の http://LANアドレスだけでは、スマホへのインストールとオフラインキャッシュを利用できません。

1. HTTPSに対応した静的サイト置き場（例：GitHub Pages、Netlify、Cloudflare Pages）を用意します。
2. 次のアプリファイルを置き場の公開フォルダへ配置します。
   index.html / detail.html / manifest.webmanifest / sw.js
   css/ / js/ / icons/ / personas/ / targets/
   P3R-Dashboard-TODO.html やこの案内ファイルは公開に必要ありません。
3. 発行されたHTTPSアドレスをスマホで開きます。初回はオンラインのまま少し待ち、アプリ画面が表示されてから閉じてください。
4. Android（Chrome）：ブラウザメニューから「アプリをインストール」または「ホーム画面に追加」を選びます。
   iPhone（Safari）：共有ボタンから「ホーム画面に追加」を選びます。
5. 追加されたアイコンから一度起動した後、機内モードで開けることを確認します。

アプリファイルを更新した場合
----------------------------
ファイル一式を同じHTTPS置き場へ再配置してください。Service Workerの版を上げると、端末は次回のオンライン起動時に新しいファイルを取り込みます。現在の版は sw.js の CACHE_NAME で管理します。

注意
----
- PWAはHTTPSの公開アドレスから配信してください。ホーム画面追加に使うURLを他の人へ共有すると、その人もサイトを開けます。
- ページ内の外部攻略リンクは、オフライン中は開けません。ダッシュボード本体と保存済みメモは利用できます。
- ブラウザのサイトデータを削除すると、その端末内の進捗も消える場合があります。定期的にバックアップを書き出してください。
