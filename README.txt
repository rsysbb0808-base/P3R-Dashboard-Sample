P3R Personal Dashboard 更新版

スマートフォン用PWA（ホーム画面に追加できるWebアプリ）として利用できます。設置・オフライン利用の手順は SMARTPHONE-SETUP.txt を参照してください。PWAの初回読み込みにはHTTPS接続が必要です。

構成
- personas/: 所持ペルソナ11体の詳細ページ
- targets/: 育成目標9体の詳細ページ
- detail.html / js/detail.js: 共通詳細表示・ローカル保存
- css/style.css: 共通デザイン
- js/app.js: トップ画面、進捗、コミュ、期限メモ、合体プラン、日誌、バックアップ
- manifest.webmanifest / sw.js / js/pwa.js: ホーム画面への追加とオフライン用キャッシュ
- icons/: アプリアイコン

追加機能
- 期限メモ: ゲーム内日付と、満月作戦・救出・コミュなどの予定を登録し、残り日数を表示
- 合体プラン: 目標ごとの代表レシピ、現在所持素材、主人公レベルと解禁条件を確認
- 合体候補の素材名から共通詳細ページを開き、アルカナ・基礎レベル・入手の目安と外部レシピ表を確認
- 入手欄に合体可能な主人公レベル、確認できたシャッフルタイム階層、コミュ／リンクエピソード／依頼の解禁条件を表示
- 「ジャアクフロスト」の個人記録と、ブラックフロスト素材の「ジャックフロスト」は別に扱う
- 所持ペルソナ欄の「現在所持」チェックは合体プランと連動
- 期限、所持状態、解禁チェックも localStorage と既存バックアップに保存
- スマホを主端末として、画面サイズに合わせた1列カード、タップしやすい入力欄・操作ボタンを用意
- データ同期は行わず、アプリを使う端末内に保存
- 合体候補は代表例です。DLCや解禁状況により変わるため、実際の合体画面で確認してください

主な修正
- セタンタを星アルカナ Lv.29に訂正
- 白虎を節制 Lv.63、コロマルのリンクエピソード完了で解放と記載
- パールヴァティの固定特殊合体素材をサティ＋サラスヴァティ＋ダキニと記載
- ブラックフロストを固定特殊合体として記載
- 「ジャアクフロスト」はP3R内の表記との照合が必要なため、ユーザー記録の名称を維持し確認表示にした
- 主人公Lv.42からは通常作成レベルに届かない目標（Lv.48以上）を後半目標として注記
